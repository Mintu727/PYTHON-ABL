# Algorithm — Internship Candidate Ranking

1. Read academic, assessment and attendance data.
2. Calculate academic average.
3. Calculate weighted score: 50% academics, 40% assessment, 10% attendance.
4. Check minimum eligibility thresholds.
5. Rank by weighted score then assessment.
