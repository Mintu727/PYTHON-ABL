# Multi-Criteria Internship Candidate Ranking

**Case study 82**

## Problem statement
Shortlist and rank internship candidates using academic average, assessment score and attendance.

## Objectives
- Apply Python problem-solving techniques to the stated case.
- Process and validate structured data.
- Produce a clear report using the program output.

## Assumptions
Weighted score = 50% academic average + 40% assessment + 10% attendance; eligibility requires average >= 65, assessment >= 60 and attendance >= 75.

## Algorithm
1. Start and initialize the sample data.
2. Traverse the records using loops.
3. Apply the required validation, calculations and decision rules.
4. Store and organize the results.
5. Display the final report.
6. Stop.

## Concepts used
Lists, tuples, nested lists, loops, conditions, selection sort.

## Run
```bash
python main.py
```
