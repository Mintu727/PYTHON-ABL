# Algorithm — Smart Campus Management

1. Initialize student records and event lists.
2. Display menu inside a loop.
3. Read and validate menu choice.
4. Process student view, attendance, registration or summary.
5. Prevent unknown IDs and duplicate registrations.
6. Repeat until Exit is selected.
