# Comprehensive Smart Campus Management Simulation

**Case study 100**

## Problem statement
Build a menu-driven campus system integrating student records, attendance, event registration and summary reporting.

## Objectives
- Apply Python problem-solving techniques to the stated case.
- Process and validate structured data.
- Produce a clear report using the program output.

## Assumptions
Uses a fixed demonstration dataset; students may register once per event; attendance eligibility threshold is 75%.

## Algorithm
1. Start and initialize the sample data.
2. Traverse the records using loops.
3. Apply the required validation, calculations and decision rules.
4. Store and organize the results.
5. Display the final report.
6. Stop.

## Concepts used
Variables, input/output, strings, lists, nested lists, tuples, loops, conditions, membership.

## Run
```bash
python main.py
```

## Test cases
- Normal valid input/data: verify that the expected result is produced.
- Boundary condition: verify values at the stated thresholds.
- Invalid or duplicate data (where applicable): verify that it is detected or rejected.

## Conclusion
The program demonstrates the listed Python concepts through a practical case study and reports the computed results.
