# Algorithm — Disaster Relief Allocation

1. Read area demand and urgency tuples.
2. Sort areas by urgency (1 is highest).
3. Set remaining stock to available stock.
4. Allocate the minimum of demand and remaining stock.
5. Update stock and unmet demand; report totals.
