# Algorithm — University Admission

1. Read applicant and course details.
2. Calculate aggregate percentage.
3. Apply course-specific subject and aggregate cut-offs.
4. Separate eligible and rejected applicants.
5. Rank each course by aggregate then Mathematics marks.
