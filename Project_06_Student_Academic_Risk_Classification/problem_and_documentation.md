# Student Academic Risk Classification

**Case study 66**

## Problem statement
Classify students into high, medium or low academic risk using marks, attendance and laboratory scores.

## Objectives
- Apply Python problem-solving techniques to the stated case.
- Process and validate structured data.
- Produce a clear report using the program output.

## Assumptions
High risk if average < 50 or attendance < 65 or lab < 40; medium risk if average < 65 or attendance < 75 or lab < 50; otherwise low risk.

## Algorithm
1. Start and initialize the sample data.
2. Traverse the records using loops.
3. Apply the required validation, calculations and decision rules.
4. Store and organize the results.
5. Display the final report.
6. Stop.

## Concepts used
Nested lists, tuples, conditions, loops, counters.

## Run
```bash
python main.py
```
