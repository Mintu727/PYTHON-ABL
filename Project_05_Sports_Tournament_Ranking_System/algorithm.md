# Algorithm — Sports Tournament Ranking

1. Initialize team statistics.
2. Process each match tuple.
3. Update goals scored and conceded.
4. Award 3 points for win, 1 for draw, 0 for loss.
5. Rank by points, goal difference and goals scored.
